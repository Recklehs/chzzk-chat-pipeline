# Report Documentation Design

## Goal
- 분석 산출물과 카탈로그 문서를 나중에 쉽게 다시 찾고 해석할 수 있도록 README에 인덱스를 추가한다.
- 주요 `cmd`가 어떤 메시지 유형인지 예시와 함께 설명하는 별도 문서를 만든다.

## Scope
- `README.md`
  - 새 분석 문서 인덱스 섹션 추가
  - 각 리포트/카탈로그 파일에서 무엇을 알 수 있는지 설명
- `docs/chzzk_cmd_message_types.md`
  - 현재 데이터에서 관측된 주요 `cmd`의 의미 설명
  - `93101`, `93102`, `94008`, `93006`, `10100`에 대한 예시 구조 추가

## Design Notes
- README는 탐색 인덱스 역할에 집중한다.
- CMD 문서에는 상세 설명과 예시를 넣어 README가 지나치게 길어지지 않도록 한다.
- 예시는 실제 관측된 필드 구성을 바탕으로 하되, 사용자 메시지 텍스트는 공격적 표현이 있을 수 있으므로 구조 중심의 축약 예시를 사용한다.

## Verification
- README에 추가한 링크와 새 문서 경로가 실제 존재하는지 확인한다.
- 문서 헤더와 주요 섹션을 직접 읽어 누락된 설명이 없는지 검토한다.
