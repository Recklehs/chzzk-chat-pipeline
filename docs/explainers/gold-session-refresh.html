성적표는 방송마다 한 장입니다. 무슨 일이 생겼는지 골라 보세요.

회차 1–8은 실제 수집 기록이고, 9번(방송 중)은 설명을 위한 예시입니다.

다시 센다는 것

방송 한 회를 처음부터 다시 세니까 정확합니다

계산은 전체 재계산과 같은 Gold 코드를 씁니다. 범위만 “전체”에서 “바뀐 방송”으로 좁힙니다.

왜 이 방법인가

다른 방법은 이래서 안 맞습니다

✗ 계수기스트리밍 집계

더하기만 해서 빠릅니다. 하지만 공백·피크·0건은 못 세고, 정확한 사람 수는 워터마크만큼(예: 10분) 늦게 나옵니다.

✗ 전부 다시처음 만든 배치 (지금은 --full)

정확하지만 쌓인 데이터 전체를 매번 셉니다. 쌓일수록 느려지고, 라이브가 아닙니다.

✓ 바뀐 방송만채택한 방식

정확하고, 10초마다 갱신됩니다. 끝난 방송은 건드리지 않아서 1년 치가 쌓여도 한 번에 하는 일의 양이 같습니다.

드문 경우를 위한 안전장치

아주 가끔은 전부 다시 셉니다

한 번도 일어나지 않은 경우를 위해 구조를 무겁게 만들지 않습니다. 진행 중인 방송은 매번 다시 세므로 자동으로 맞춰지고, 끝난 방송만 “전부 다시”로 보정합니다.
